# 四、Alpaca 放在哪里？

不要让 React 前端直接调用 Alpaca。

```text
React
   │
   ▼

   │
   ▼
Alpaca API
```

例如：

```text
GET /api/stocks/AAPL/quote

        ↓

StockController

        ↓

StockService

        ↓

AlpacaClient

        ↓

Alpaca Market Data API
```

Alpaca 目前同时提供 Java SDK，所以我们的 Java 后端可以直接集成。([Alpaca US][4])
