XtQuant 实盘接口 是**迅投（ThinkTrader/QMT）**提供的一套 Python 量化交易 API，主要用于连接 MiniQMT/QMT 客户端，实现 A股、ETF、可转债、期货、期权 等市场的程序化交易。它是目前国内个人量化交易中最流行的实盘接口之一。

它主要由两个模块组成：

模块	功能
xtdata	获取行情、历史K线、Tick、Level2、财务数据等
xttrader	实盘交易：下单、撤单、查询持仓、查询成交、查询资金等

主要特点

优点：

官方支持 Python
实盘速度快，延迟低
支持事件回调（成交、委托、持仓变化）
可获取实时行情和历史行情
支持自动化交易

缺点：

仅支持 Windows
需要先启动并登录 MiniQMT/QMT 客户端
不同券商支持情况可能不同，部分交易权限需券商开通
